How this stays accurate

  • Request mode (Tweaks): sends treatment, office, day, time window, name and phone to the front desk through the same Zapier flow as the lead forms. Nothing is booked until the desk confirms, so it can never double-book.
  • Instant mode (Tweaks): shows open times pulled from Square and books the exact slot. Needs a small server on Vercel that calls Square's booking system, so the Square account details never reach the browser.
  • Only treatments set to "bookable online" in Square appear, so prices, lengths and providers match Square exactly.
  • The concierge only answers from Avere's own content (services, offices, policies). It can't diagnose or quote prices it hasn't been given. It hands off to 412-952-7592 when unsure, and every chat that ends in a booking goes to the front desk.
